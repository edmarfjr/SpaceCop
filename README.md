# StarCop

Roguelike de cartas para celular, em paisagem: mapa no estilo Slay the Spire
e batalhas em tempo real numa grade 6×3. A jogadora é uma policial espacial;
a primeira missão é contra uma organização criminosa.

Flutter + Flame. Domínio puro em `lib/domain`, Flame em `lib/game`, overlays
Flutter em `lib/ui`. Direção visual em `DESIGN.md`.
